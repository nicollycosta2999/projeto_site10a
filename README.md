# TechNews Today - Portal de Tecnologia 📱

## Sobre o projeto

Este projeto foi desenvolvido como uma atividade de HTML e CSS. A ideia foi criar uma página de um portal de notícias sobre tecnologia, com uma aparência moderna e organizada.

A página apresenta uma notícia de destaque sobre Inteligência Artificial, uma área com vídeo do YouTube e um formulário de inscrição para uma newsletter.

## Tecnologias utilizadas

- HTML5
- CSS3
- YouTube

## O que foi utilizado

No HTML foram utilizados elementos como:

- Cabeçalho (`header`)
- Títulos e parágrafos
- Artigo (`article`)
- Seções (`section`)
- Vídeo com `iframe`
- Formulário
- Campo de e-mail
- Lista de opções
- Checkbox
- Botão
- Rodapé (`footer`)

No CSS foram utilizados recursos como:

- Cores e gradientes
- Bordas arredondadas
- Efeitos ao passar o mouse
- Grid
- Responsividade
- Organização dos elementos da página

## Objetivo

O objetivo da atividade foi praticar a criação de uma página utilizando HTML e CSS, aprendendo a organizar os elementos e deixar o site mais bonito e responsivo.

## Resultado

O resultado foi uma página de notícias sobre tecnologia com tema escuro, contendo uma notícia principal, vídeo e formulário de newsletter.
